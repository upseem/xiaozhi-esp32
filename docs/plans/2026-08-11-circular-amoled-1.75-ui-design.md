# Waveshare ESP32-S3-Touch-AMOLED-1.75 圆屏 UI 设计

日期：2026-08-11  
范围：`main/boards/waveshare/esp32-s3-touch-amoled-1.75/`（含 1.75 / 1.75C）

## 背景

板载 466×466 圆形 AMOLED。小智默认 LCD UI 按矩形布局，字幕贴底且接近全宽，在圆屏上下边缘被圆弧裁切，出现「半个字」。

## 目标

- 按 466×466 正方形 framebuffer 设计，可见内容落在直径 **450** 的安全圆内；圆外保持黑底。
- 表情在上方；字幕在中下多行。
- 文字按圆弦逐行限宽换行，禁止字符被圆弧裁半。
- 待机只保留表情 + 状态文案（待机 / 听你说 / 说话中等），**不显示时钟**。

## 方案选择

采用 **板级定制默认 UI**（不改全局 `lcd_display.cc`，不影响方屏板）：

1. `CustomLcdDisplay::SetupUI()` 重排表情 / 状态 / 字幕区几何。
2. `SetChatMessage()` 先做圆弦预换行，再交给 LVGL label。
3. `SetStatus()` 拦截 idle 时钟 `HH:MM`，改为保持 `STANDBY` 等业务状态。

不采用完整自研圆形字幕控件（成本高）；不采用固定小矩形（浪费圆内空间）。

## 几何

| 常量 | 值 |
|------|-----|
| 画布 | 466 × 466 |
| 安全圆直径 | 450（半径 R = 225） |
| 圆心 | (233, 233) |
| 行左右边距 | 约 12–16 px |

行宽公式（行中心 Y）：

```
max_w(y) = 2 * sqrt(R² - (y - cy)²) - 2 * edge_pad
```

分区（约）：

- 顶部状态安全带：y ≈ 20–70  
- 表情：y ≈ 50–180，偏上固定  
- 字幕：y ≈ 190–420，中下多行，区内可滚  

## 布局行为

| 状态 | 表现 |
|------|------|
| 待机 | 表情 + 状态「待机」；无大时钟；无字幕 |
| 聆听 / 说话 | 表情仍在上；状态更新；字幕显示时占中下 |
| 空字幕 | 隐藏字幕区 |
| 长文 | 字幕区固定高度内滚动，不顶走表情、不撑出圆外 |

## 圆形换行

在 `SetChatMessage` 中：

1. 取当前主题字体与行高。  
2. 从字幕区顶行起，按行中心 Y 算 `max_w(y)`。  
3. 中文按字符、拉丁尽量按词测量 `lv_txt_get_width`（或等价），装入当前行；超宽则换行并重算下一行弦宽。  
4. 生成带 `\n` 的字符串，`LV_LABEL_LONG_WRAP` 显示。  
5. 容器限高 + 可垂直滚动（或保留尾部可见）。

## 非目标

- 不做微信气泡样式圆屏适配（本板默认关闭）。  
- 不改其他 Waveshare 圆屏板（除非后续复用 helper）。  
- 不做弧形沿边排字（沿弦的矩形行即可）。

## 验收

1. 待机：表情在上、状态可见、无时钟。  
2. 对话字幕在中下多行，左右无半字裁切。  
3. 长句仍落在直径 450 安全圆内。  
4. 圆外仅黑底，无 UI 贴边溢出。  
5. 1.75 与 1.75C 行为一致。
